# 行测助手

一个本地静态网页版行测训练工具，当前包含基础练习和资料专项两类训练。

## 功能

- 基础练习：加减乘除、估算等速度训练。
- 资料专项：增长相关、比重相关题型训练。
- 自动判题：支持精确答案和相对误差范围判定。
- 计时记录：支持总用时和单题用时，精度到毫秒。
- 做题记录：本地保存记录，支持筛选、查看题目报告、单条删除、清空记录。
- 数据导出：支持将做题记录导出为 CSV 表格。
- 快捷键：Enter 下一题，Shift 上一题，空格开始新练习。

## 使用

直接打开 `index.html` 即可使用。

如果希望以无浏览器地址栏的小窗口打开，可以运行：

```bat
open-app-window.bat
```

## 数据存储

做题记录保存在浏览器 `localStorage` 中。更换浏览器、清理站点数据或手动清空记录会影响历史数据。
